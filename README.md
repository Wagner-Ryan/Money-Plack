Money-Plack

Project Goal
 - Build a function financial planning and tracking application that allows users to track finances online

Target Audiences
 - Myself, any user who finds it an appealing way to managing their finances

Core Features (The Minimum Viable Product)
 - User Authenication: Simple Login/Sign-Up (Email or Google)
 - Budgetting CRUD: Create, Read, Update, and Delete items
 - Planning CRUD: Create, Read, Update, and Delete items
 - Persistence: Budget and Plans are saved in a database so they are there on refresh

Technical State
 - Frontend (will be researching yet - examples: baseline HTML+CSS, React, Next.js)
 - Backend (will be researching yet - examples: personal server/python/js, Node.js)
 - Database (will be researching yet - examples: PostgreSQL, AWS, local)
 - Deployment (will be researching yet - examples: Vercel or Netlify)

Success Metrics / "Definition of Done"
 - The website is live on a public URL from any computer
 - A user can log in, create a budget, make a financial plan, and see them still there after logging out and back in
 - All data in the database is encrypted and secure
